# Supplier Assets

Place approved supplier images in this directory:

## Disney
- Source: DisneyTravelAgents.com → "Disney Content Connection"
- Naming convention: `disney-[ship-or-park]-[descriptor].jpg`
- Example: `disney-wish-hero.jpg`, `disney-castaway-cay.jpg`

## Virgin Voyages
- Source: Virgin "First Mates" portal via BNT Travel Group
- Naming convention: `virgin-[ship]-[descriptor].jpg`
- Example: `virgin-scarlet-lady-hero.jpg`, `virgin-beach-club.jpg`

## Guidelines
- Use only pre-approved, partner-compliant images
- Recommended resolution: 1200×800px minimum for hero cards
- Format: JPG or WebP preferred for performance
